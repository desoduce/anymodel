About ChatinShield

ChatinShield is a privacy-first mobile application that connects to multiple Large Language Models (LLMs) including OpenAI GPT, Anthropic Claude, Google Gemini, and OpenRouter. The app features:

  • Advanced PII (Personally Identifiable Information) filtering
  • Secure local storage for API keys
  • Document processing (DOCX, Excel, Text)
  • No data collection - everything stays on your device
  • Production-hardened security with file size limits
